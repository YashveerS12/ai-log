# AI Log — 2026-10-28

The first neural network trained on a dataset of handwritten digits, the MNIST dataset, was created in 1998 by Yann LeCun and colleagues to test the LeNet-5 architecture.  
It contains exactly 60,000 training images and 10,000 test images, each 28×28 pixels.  
LeNet-5 won the 1998 International Conference on Pattern Recognition by achieving 99.2% accuracy, a benchmark that still inspires modern CNNs.
